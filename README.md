# Chess Opening Explorer

**Chess Opening Explorer** is an interactive educational web application for exploring chess openings step by step.

The application allows users to explore the three main starting moves — **1.e4, 1.d4 and 1.c4** — and follow different opening branches through an interactive chessboard. Each selected move updates the board, move history and available continuation options.

The opening tree includes well-known openings and defenses such as the **Sicilian Defense, French Defense, Caro-Kann Defense, Ruy Lopez, Italian Game, King's Gambit, Queen's Gambit, Slav Defense, King's Indian Defense, Nimzo-Indian Defense, English Opening** and others.

## Features

* Interactive chessboard
* Step-by-step move exploration
* Opening tree with multiple branches
* Move history / move ledger
* Opening and variation names
* Short educational descriptions
* Back and reset navigation
* Support for **1.e4, 1.d4 and 1.c4**
* Responsive layout for different screen sizes

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript

## Project Level

**Frontend Level 3 — Structured Frontend Developer**

The project focuses on structured JavaScript data, application state, dynamic DOM rendering, branching logic and a custom move-processing system.

## Purpose

The project was created as an educational tool for learning and organizing chess openings while practicing more advanced **JavaScript logic, state management and dynamic UI rendering**.
